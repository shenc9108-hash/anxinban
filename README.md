# 安心伴 完整骨架（后端 + 家长端 + 孩子端）

目录
- server/         Node 后端，同时托管家长端网页（手机浏览器即可用，安卓、鸿蒙、iPhone 都能开）
- child-android/  Android 孩子端（Kotlin，Android Studio 打开）

## 一、起后端（电脑上，Node 18+）
    cd server
    PARENT_KEY=你的密码 node server.js      # Windows: set PARENT_KEY=你的密码 && node server.js
电脑和手机连同一个 WiFi，查电脑局域网 IP（如 192.168.1.20）。

## 二、家长端
手机浏览器打开 http://电脑IP:3000 ，输入家长密钥，点「生成绑定码」。
可添加到主屏幕当 App 用。

## 三、孩子端
1. 不用改代码：在孩子端首页的“服务器地址”里填 IP 或域名即可，以后换地址只要在孩子端重新填一次。
2. Android Studio 打开 child-android，Run 到孩子手机。
3. 打开 App：输入绑定码 -> 绑定；开启无障碍服务；允许通知、关闭电池优化。
4. 在家长端给孩子设置应用限时（填包名，如微信 com.tencent.mm），孩子手机会按规则拦截；孩子点「申请再用 15 分钟」，家长端出现审批卡片。

## 定位与电子围栏
1. 孩子端点「3. 开启位置权限」，选“使用时允许”，再按系统提示改为“始终允许”。
2. 家长端「位置与电子围栏」卡片会显示坐标，点「地图查看」用高德打开（已做坐标偏移换算）。
3. 孩子在目标地点（如家）时，填围栏名和半径，点「以当前位置添加」。之后孩子进出围栏，顶部会出现“围栏提醒”。
4. 国内手机的系统定位服务要开启；室内精度可能有几十米，半径建议不小于 150 米。

## 提示
- 绑定后家长端 5 秒刷新一次；孩子端每 30 秒同步规则，所以改规则最多延迟 30 秒。
- 上线给别人用前必须：换成 https 和正式域名、改掉默认密钥、做账号体系和数据库（现在是单家庭演示，数据存 db.json）。
- 孩子端后续任务见 child-android/README.md。
